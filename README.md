# 리듬 채보 만들기 (rhythm-chart-web)

**바로 열기: https://pass1948.github.io/rhythm-chart-web/**

음원 파일을 올리면 브라우저 안에서 박자와 소리 시작 지점을 분석해 2레인 리듬게임 채보(노트)를 만들고, 직접 다듬은 뒤 바로 게임 화면에서 쳐 볼 수 있는 웹 프로그램입니다.

- 서버가 없습니다. 음원은 내 브라우저 밖으로 전송되지 않습니다.
- PC와 모바일 브라우저(크롬, 엣지 등)에서 쓸 수 있습니다.
- 분석 → 노트 자동 생성 → 편집(단타·롱노트·연타, 파형 보기, 변속 구간) → 테스트 플레이(판정·볼륨 설정) → 내보내기(JSON, 음원, JSON+음원 ZIP) 순서로 작업합니다.

이 저장소에는 빌드된 웹페이지 파일만 올라갑니다.
