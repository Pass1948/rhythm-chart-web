# 4키 노트 생성

난이도와 구간을 고른 뒤 노트 자동 생성을 누릅니다. 시작 2초와 끝 1초는 비워 둡니다. 기존 노트는 재생성을 확인한 뒤 교체됩니다. 2키 파일은 열어서 편집할 수 있습니다.

고급 규칙에서 같은 손과 레인의 간격, 한 번에 누르는 수, 롱노트 길이와 해제 후 간격을 조절합니다. 건강검진에서 오류나 경고를 누르면 해당 노트로 이동합니다. Glitch의 Unity 저장 이름은 GLIITCH입니다.

측정은 프로젝트 루트에서 `node tools/measureGeneration.mjs`로 실행합니다. 이전 소스를 푼 폴더를 인자로 주면 옛 unified 모드 결과를 같은 양손 규칙으로 검사합니다. 제외율은 구간 내 격자 후보 중 결과에 없는 시작 tick 비율입니다. 강박 유지율은 그중 박 위치에 있던 후보의 유지 비율입니다. 두 비율은 곡별로 계산한 뒤 평균을 냅니다.
